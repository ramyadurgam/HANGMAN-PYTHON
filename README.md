# HANGMAN-PYTHON
A colourful text-based Hangman game in Python, built for the CodeAlpha Internship (Task 1). Guess a random coding-themed word with 6 lives, a self-drawing hangman, a live A-Z keyboard, hints, whole-word guesses, input validation, win streaks and replay. Uses random, while loops, if-else, strings, lists and functions. No external libraries.
